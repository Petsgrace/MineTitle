Key Data Flows

  1. Registration → Verification: National ID flows from farmer registration through Registrar General API for bio-data auto-population (DOB, Marital Status, Gender, Life Status).
  2. Land Verification Pipeline: Sequential checks through Lands DB → Surveyor General → ZLC, with pause/resume capability at each gate for unresolved issues.
  3. Valuation Pipeline: Lookup-first approach using predefined valuation tables, with automated calculation fallback based on land attributes and Natural Region.
  4. Payment Branching: Cash path applies immediate 15% discount; mortgage path routes through Dokuma API for bank selection and agreement processing.
  5. Cross-Portal Collaboration: Inter-agency messaging with @mentions spans all admin portals, with every action logged to the immutable audit trail.
  6. Dokuma Outbound: OTDAS sends National ID, property description, and secure URLs for Agreement of Sale and Declaration by Purchaser to the Dokuma API.
